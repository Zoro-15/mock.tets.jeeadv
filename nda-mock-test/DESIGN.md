# NDA Mock Test Platform - Design Guidelines

This document details the visual identity, tokens, and style guide for the NDA Mock Test application.

## 1. Vision & Aesthetics
- **Theme**: Premium modern dark mode.
- **Aesthetic**: Minimalist, clean cards, rounded corners, subtle borders, high contrast for text readability.
- **Atmosphere**: Focused, fast, academic, mimicking real exam environments without visual clutter.

## 2. Design Tokens
- **Background**: `#0F172A` (slate-900)
- **Surface**: `#1E293B` (slate-800)
- **Primary**: `#3B82F6` (blue-500)
- **Success**: `#22C55E` (green-500)
- **Warning**: `#F59E0B` (amber-500)
- **Danger**: `#EF4444` (red-500)
- **Text Primary**: `#F8FAFC` (slate-50)
- **Text Secondary**: `#CBD5E1` (slate-300)

- **Radius**:
  - `rounded-xl` (12px) - Cards, buttons, inputs.
  - `rounded-2xl` (16px) - Banners, main containers, dialogues.

- **Spacing (Tailwind standard equivalents)**:
  - 8px: `p-2`/`gap-2`
  - 12px: `p-3`/`gap-3`
  - 16px: `p-4`/`gap-4`
  - 24px: `p-6`/`gap-6`
  - 32px: `p-8`/`gap-8`

- **Typography**:
  - Main Font: **Inter**
  - Primary text should have a default size of `text-base` (16px).
  - Secondary details and tags use `text-sm` (14px) or `text-xs` (12px).

## 3. Keyboard Shortcuts
- `1`, `2`, `3`, `4` - Select Options A, B, C, D respectively.
- `N` - Save & Next.
- `M` - Mark for Review & Next.
- `C` - Clear Response.
- `P` - Toggle Question Palette.
